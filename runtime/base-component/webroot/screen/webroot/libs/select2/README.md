# Java-compatible dropdown assets

Select2 4.0.3 (MIT), Select2 Bootstrap Theme 0.1.0-beta.10 (MIT), and jQuery (MIT) are copied unchanged from the Java reference webroot. Their copyright/license headers are retained. The HTML client loads these local assets only for dropdown widgets. Tom Select continues to handle text-line autocomplete and ordering controls.

Upstream sources: https://github.com/select2/select2/tree/4.0.3 and https://github.com/select2/select2-bootstrap-theme/tree/0.1.0-beta.10 and https://jquery.com/ .
